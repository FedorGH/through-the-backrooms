## 🚪 О проекте

**The Backrooms: Threshold** - тизер

### 📖 Концепция
- 🏢 **Аутентичная атмосфера** Бэкрумс согласно каноническому описанию
- 🔊 **Амбиентный саундтрек** с 3D позиционным звуком
- 👁️ **Эффекты расстройства восприятия** и парейдолии

## 🎯 Особенности тизера

### 🌟 **Демонстрируемые возможности**
- 🎨 **Визуальный стиль** - точное воспроизведение эстетики Level 0
- 🔊 **Звуковой дизайн** - гул люминесцентных ламп, отдаленные шаги
- 🏃 **Плавное движение** с эффектом дезориентации
- 💡 **Динамическое освещение** с мерцающими лампами
- 🌫️ **Пост-обработка** - зернистость, хроматические аберрации, виньетирование
-
